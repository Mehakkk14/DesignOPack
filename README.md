# Designopack Luxury Showcase

Designopack is a premium luxury packaging showcase platform that displays high-end packaging products with an elegant, interactive experience for customers to explore packaging solutions.

## Features

- **Product Catalog**: Browse luxury packaging products organized by categories
- **Product Details**: View detailed product information with high-quality image galleries
- **Quote Request System**: Submit custom quote requests for products
- **WhatsApp Support**: Direct customer support integration
- **Admin Panel**: Secure admin dashboard for managing products, categories, banners, and quote requests

## Admin Access

Admin panel is accessible at `/admin/login` for authorized users to manage:
- Products and categories
- Customer quote requests
- Homepage banners
- Product ordering and organization

## Technical Information

Built with modern web technologies:
- React with TypeScript
- Firebase (Database & Authentication)
- Responsive design for all devices
- SEO optimized
